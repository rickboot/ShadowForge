# B/X D&D to Shadowdark Conversion

**Compatibility: 95% - Minimal conversion needed**

B/X D&D (1981) is Shadowdark's spiritual ancestor. Most elements translate directly.

## Character Classes

### Race-as-Class Conversion
- **Elf** → Elf ancestry + Fighter or Wizard (player choice)
- **Dwarf** → Dwarf ancestry + Fighter
- **Halfling** → Halfling ancestry + Thief
- **Human Classes** → Direct conversion:
  - Fighter → Fighter
  - Cleric → Priest
  - Magic-User → Wizard
  - Thief → Thief

## Armor Class
- **AC 9 (unarmored)** → **AC 10** (Shadowdark base)
- All other AC values remain the same
- Shields still provide +2 AC

## Hit Points & Hit Dice
Use exact same Hit Dice progression:
- **Fighter:** d8 per level
- **Cleric:** d6 per level
- **Magic-User:** d4 per level
- **Thief:** d4 per level

## Spells
**Direct Conversion:**
- Spell levels 1-5 convert directly to tiers 1-5
- B/X spell descriptions work with minor wording updates
- Add Shadowdark spellcasting failure mechanics per core rules

## Combat
- **Initiative:** Use Shadowdark d20 + DEX instead of B/X group initiative
- **Attack rolls:** Convert "roll d20, compare to target AC" directly
- **Damage:** Keep exact same weapon damage dice

## Monsters
**Minimal changes required:**
- **Hit Dice:** Use as-is (e.g., "3 HD" = Level 3, 3d8 HP)
- **Armor Class:** Use B/X AC directly (or convert AC 9→10 if needed)
- **Attacks:** Convert damage directly (e.g., "1d6 damage" stays 1d6)
- **Special Abilities:** Translate to simple Shadowdark format

## Treasure
- **Monetary:** Use B/X values directly or divide by 10 for smaller economies
- **Magic Items:** Convert using universal mechanics
- **XP Values:** Use Shadowdark treasure-based XP system

## Examples

### B/X Goblin Conversion
**B/X:** AC 6, 1-1 HD, 1d6 damage
**Shadowdark:** Level 1, AC 14, HP 3, +1 attack, 1d6 damage

### B/X Ogre Conversion  
**B/X:** AC 5, 4+1 HD, 1d10 damage
**Shadowdark:** Level 4, AC 15, HP 20, +4 attack, 1d10 damage

**Note:** B/X ogres were traditionally countered by Sleep spell. Consider reducing to Level 2-3 if players lack tactical options.
